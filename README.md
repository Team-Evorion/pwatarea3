
# Práctica 3 – Programación Web Avanzada

Proyecto académico desarrollado para la asignatura de **Programación Web Avanzada** de la Universidad Bolivariana del Ecuador (UBE).

## Descripción

Esta práctica integra seis ejercicios de desarrollo web en una interfaz principal, diseñada para facilitar la navegación y el acceso a cada actividad.

El proyecto combina diseño web, interactividad, validación de datos, procesamiento mediante PHP y almacenamiento de información.

## Ejercicios

| Ejercicio | Descripción |
|-----------|-------------|
| 01 | Primera actividad práctica |
| 02 | Formulario interactivo con validaciones y vista previa en tiempo real |
| 03 | Contador de visitas con estadísticas e historial de actividad |
| 04 | Cuarta actividad práctica |
| 05 | Quinta actividad práctica |
| 06 | Sistema de registro, inicio de sesión y autenticación de usuarios con MySQL |
