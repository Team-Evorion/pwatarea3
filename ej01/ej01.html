01 El contenido adicional aparece únicamente cuando se solicita.

01 / INTERACCIÓN

Oculto al inicio.
Visible al hacer clic.

El menú cumple el objetivo principal del ejercicio: las opciones adicionales permanecen ocultas hasta que el usuario activa el elemento principal.

Volver y probar ↑

02 / FUNCIONAMIENTO

Tres movimientos.
Una interacción natural.

  1. 01

    Activa

    Haz clic en uno de los botones de la navegación principal.

  2. 02

    Explora

    Revisa las opciones que aparecen sin abandonar ni recargar la página.

  3. 03

    Cierra

    Selecciona una opción, presiona Escape o haz clic fuera del menú.

03 / CONSTRUCCIÓN

Tres archivos.
Responsabilidades claras.

01 — HTML

Estructura

Botones, listas, enlaces y atributos ARIA forman una navegación comprensible.

02 — CSS

Presentación

La jerarquía visual, el movimiento y el diseño adaptable mantienen el menú legible.

03 — JS

Comportamiento

La lógica controla apertura, cierre, foco y navegación mediante teclado.
